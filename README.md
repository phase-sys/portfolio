# Business-Oriented Software Portfolio (TypeScript Edition)

This is a high-performance, solution-oriented portfolio for a Full-Stack Software Engineer, designed to attract high-paying enterprise clients and businesses.

## 🚀 Strategic Positioning
The portfolio has been transformed from a "developer's resume" into a "solution-oriented" business site.
- **Hero Focus:** Streamlining business operations through custom software.
- **Service Framing:** Technical skills (Android, Web, Desktop) are presented as ROI-driven business solutions.
- **Case Study Framework:** Flagship projects like the PFDA Windows Infrastructure focus on the "Business Challenge," "Strategic Solution," and "Measurable Result."

## 🎨 Brand Identity (OKLCH + Type)
The project uses a modern, high-contrast palette defined in OKLCH for consistent perceived brightness.
- **Primary:** Káya Pear `oklch(0.82 0.19 128)` — Main CTA / Branding.
- **Secondary:** Káya Blue `oklch(0.7 0.12 240)` — Interactive accents.
- **Typography:** **Plus Jakarta Sans** (Headings) & **Inter** (Body) for a premium architectural feel.
- **Vibe:** Glassmorphism, Grainy noise textures, and deep-dark aesthetics.

## 🛠️ Tech Stack
- **Framework:** Next.js 16.2 (App Router)
- **Language:** TypeScript 5.9+
- **Styling:** Tailwind CSS v4 (Native OKLCH support)
- **Infrastructure:** Vercel Analytics & Speed Insights
- **Package Manager:** pnpm v10

## Getting Started
First, install dependencies and run the development server:

```bash
nvm use # requires .nvmrc setup (v24.13.0)
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
